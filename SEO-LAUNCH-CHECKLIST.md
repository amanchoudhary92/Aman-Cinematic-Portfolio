## Before deployment
1. Copy `.env.example` to `.env.local` and set the final public origin:
   `NEXT_PUBLIC_SITE_URL=https://your-domain.com`
2. Run:
   - `npm run build`
   - `npm start`
3. Test Lighthouse on the production server, not `npm run dev`.
4. Verify:
   - `/robots.txt`
   - `/sitemap.xml`
   - page source has JSON-LD
   - project pages have unique title + description
   - Open Graph preview works

## After deployment
1. Add the site to Google Search Console.
2. Verify domain ownership.
3. Submit `https://your-domain.com/sitemap.xml`.
4. Request indexing for:
   - `/`
   - `/projects`
   - `/work/campus-hub`
   - `/work/codeshield-ai`
   - `/work/mistvale-tea`
5. Link the portfolio from GitHub and LinkedIn using the same public name: **Aman Choudhary**. LinkedIn: https://www.linkedin.com/in/aman-c-1887143b1
6. After data starts arriving, optimize titles/content using actual Search Console queries instead of guessed search volume.

## Ranking reality
Technical SEO helps search engines crawl, understand and present the site. It does not guarantee a #1 ranking. The strongest long-term signals will come from useful case-study content, consistent identity, links from trusted profiles/sites, performance, and real query engagement.
