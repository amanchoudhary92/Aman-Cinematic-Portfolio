AMAN PORTFOLIO V5.9 — NEON CLOUD CMS

1. Extract the entire ZIP into a NEW folder (keep your previous working V5.9 version as backup).
2. Read NEON-CMS-SETUP.md.
3. Create Free Neon project; run neon/migrations/001_portfolio_cms.sql.
4. Configure .env.local, managed Neon Auth and admin email allowlist.
5. npm install
6. npm run verify
7. npm run test:cms
8. npm run build
9. npm start
10. Login /admin and click IMPORT ORIGINAL 3 PROJECTS.

No default admin password. Original visual design and 120 cinematic frames preserved.
